# Designspo (web app)

**Designspo** is the marketing site and web dashboard for capturing and organizing web design inspiration in one place—so you can skip scattered bookmarks and juggling accounts.

This app is built with **Next.js**: landing pages, sign-up/login (via **Supabase**), and a logged-in area to browse collections, tags, and edit screenshots synced from the companion browser extension.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Configure Supabase and API URLs in your environment variables as needed.
